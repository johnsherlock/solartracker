# P-074: Separate system capacity from Finance and fix Finance setup completion

## Objective

Introduce a dedicated installation-level system-capacity setting and correct
the Finance completion rule so valid upfront-only records count as configured.

## Scope

- Add editable system-capacity capture in Settings
- Use system capacity as the primary source for live/history capacity-based
  calculations
- Fix Finance completion so `monthlyRepayment = 0` does not make a valid
  upfront-funded record look incomplete
- Keep finance additions as historical/payment records, not the primary source
  of total PV capacity

## Out of Scope

- Broader installation-details modeling
- Battery-capacity modeling
- Redesign of the full Finance IA beyond what is needed for this separation

## Acceptance Criteria

- The Finance card on `/settings` shows complete for valid upfront-only records
- A dedicated system-capacity setting exists
- Live/history capacity-based interpretation prefers the dedicated
  system-capacity value
- Fallback behavior is explicit if system capacity is missing
- Regression coverage exists for zero-monthly upfront-funded finance records

## Dependencies

- `FE-014`
- Existing system-additions/settings flows from `P-051` / `P-052`
