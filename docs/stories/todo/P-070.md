# P-070: Deliver tariff end-date reminder emails

## Objective

Turn the existing tariff-validity reminder model into real user-facing emails so
people are warned before a tariff validity period ends and again after it has
lapsed without a replacement tariff version being supplied.

## Scope

- Deliver pre-expiry reminder emails for tariff validity end dates
- Deliver post-expiry follow-up emails when no newer tariff version has been
  entered after the previous one lapses
- Reuse the existing tariff-validity language and reminder concepts already
  defined in Settings and Tariffs
- Respect the user's saved notification preferences
- Define the first cadence clearly, such as:
  - X weeks before end date
  - after end date while still unresolved
- Ensure the emails deep-link back to the relevant tariff management flow

## Out of Scope

- Reworking tariff editing UX
- Supplier-contract lifecycle modeling beyond the existing tariff-validity model
- Multi-channel reminder delivery beyond the first email path

## Acceptance Criteria

- Users can receive reminder emails before a tariff validity period ends
- Users can receive follow-up reminder emails after expiry when no replacement
  tariff has been supplied
- Notification wording stays aligned to tariff validity rather than supplier
  contract terminology
- Reminder sends are deduplicated and auditable

## Dependencies

- `FE-018`
- Existing tariff validity/reminder data model
- Existing Settings notification preferences
