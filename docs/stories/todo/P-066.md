# P-066: Revisit Live and History pages after Overview lands

## Objective

Tidy up the Live, Historical Day, and Range History pages once Overview exists,
so the signed-in product feels like one coherent experience instead of several
strong screens that still carry first-slice assumptions or duplicated entry
patterns.

## Scope

- Review the Live, Historical Day, and Range History pages in the context of
  Overview becoming the signed-in landing page
- Remove or refine copy, prompts, and navigation assumptions that were only
  appropriate when one of those pages acted as the effective home screen
- Tighten cross-links and CTAs so each screen has a clearer role:
  - Overview = high-level summary and direction
  - Live = current-day operational view
  - Historical Day = single-day diagnosis/review
  - Range History = period-level interpretation
- Resolve small UX loose ends uncovered during the Overview rollout, such as
  duplicated explanatory text, awkward empty/loading states, or inconsistent
  shortcut language
- Add any focused regression coverage needed for the updated navigation and
  entry-point behavior

## Out of Scope

- Reopening the core financial model for Range History
- A second large visual redesign of the historical screens
- New chart families or major new analytics modules

## Acceptance Criteria

- Live and History pages no longer read like accidental landing pages once
  Overview exists
- Cross-screen CTAs and labels reflect each page's intended job clearly
- Any small trust/setup/loading-state inconsistencies uncovered by the Overview
  rollout are resolved
- Navigation between Overview and the deeper analysis screens feels deliberate
  and polished

## Dependencies

- `FE-017`
- `P-065`
- Existing Live, Historical Day, and Range History implementations
