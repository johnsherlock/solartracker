# U-060: Define contextual page help and setup value explainers

## Objective

Define the first reusable help/explainer pattern for the rewrite so new users
can quickly understand what each major page does, what decisions it supports,
and why completing optional setup fields such as tariffs, finance, and
location materially improves the product.

## Scope

- Define the first-pass help trigger pattern, such as:
  - info icon
  - help chip
  - small "What is this?" affordance
- Define the tone, length, and structure for contextual help content so it
  stays calm, concise, and trustworthy
- Define page-summary help content for the launch-critical surfaces, including:
  - public landing / sign-in entry context where relevant
  - Live
  - Historical Day
  - Range History
  - Settings home
  - key setup pages under Settings
- Define how setup surfaces explain the value unlocked by:
  - accurate tariff history
  - finance / investment details
  - exact or approximate location
- Identify which pages only need short contextual help versus which need a
  slightly richer explainer module

## Out of Scope

- Implementing the help pattern in code
- Writing a long guided walkthrough for every route
- FAQ or knowledge-base content outside the first in-app help system
- Broader marketing copy strategy

## Acceptance Criteria

- The help trigger pattern and placement rules are documented clearly enough to
  implement consistently
- The first-pass list of pages that receive help treatment is explicit
- Page-level summary content is documented for the launch-critical surfaces
- Settings/onboarding explainer content makes clear why better tariff, finance,
  and location data improve the product's output
- The content model is scoped tightly enough that implementation does not need
  to invent the meaning of each help surface ad hoc

## Dependencies

- `FE-019`
- Existing product brief, setup flow, and Range History interpretation context

## Notes

- Keep the first pass utility-first. Users should leave with "I understand what
  this page is for" and "I understand why this setup step matters," not with a
  sense that the app is forcing them through a tutorial.
