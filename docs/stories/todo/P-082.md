# P-082: Build contextual page help and setup value explainers

## Objective

Implement the first reusable in-app help pattern and the corresponding
launch-critical explainer content so users understand what each major page is
for and why accurate setup inputs materially improve the product.

## Scope

- Implement the help/explainer pattern defined by `U-060`
- Add first-pass help treatment to the agreed launch-critical surfaces
- Ensure Settings and setup flows explain the value unlocked by accurate:
  - tariff history
  - finance / investment data
  - location data
- Keep the help treatment concise, optional, and non-blocking
- Reuse one maintainable pattern across pages instead of inventing separate ad
  hoc implementations

## Out of Scope

- Long guided tours or onboarding walkthrough engines
- Per-user help-state analytics or personalization
- A full in-app documentation center

## Acceptance Criteria

- The agreed first-pass pages expose a consistent contextual help affordance
- Users can read concise page-level help without losing their place in the app
- Setup surfaces explain why better tariff, finance, and location data improve
  product output and interpretation
- The implementation is reusable enough that later pages can adopt the same
  pattern without another redesign

## Dependencies

- `U-060`
- `FE-014`
- `FE-017`
- `FE-019`

## Notes

- The goal is confidence and orientation, not exhaustiveness. If the help feels
  like a mini manual, the first pass has gone too far.
