# U-058: Redesign Period Cost Breakdown donut chart

## Objective

The current "Period Cost Breakdown" donut chart on Range History is conceptually
flawed: its slice percentages are meaningless because the values being summed
into 100% are not a coherent whole.

Define what the chart should actually communicate and how it should be
structured so that every percentage and label answers a natural user question.

## Background

The donut currently has five slices:

| Slice | Value |
|---|---|
| Import cost | €1,234.17 |
| Fixed charges | €223.99 |
| Export credit | €170.24 |
| Solar savings | €640.36 |
| Free import value | €71.77 |

ECharts sets 100% = the sum of all slice values (€2,340.53 in the example
above). That total has no meaningful real-world interpretation — it mixes:

- **Money actually spent**: import cost, fixed charges
- **Money received back**: export credit
- **Counterfactual "avoided" costs**: solar savings, free import value

Saying "import cost is 54% of the period" does not answer any question the
user is naturally asking. The chart looks informative but the percentages are
not grounded in anything.

### Free import valuation

Free import kWh (energy imported during zero-rate tariff slots) was previously
shown in kWh alongside euro values, making the mixing problem worse. It has
since been converted to an estimated euro value using the average paid import
rate: `freeImportValue = freeImportKwh × (importCost / paidImportKwh)`.

This is a reasonable proxy — it represents what those kWh would have cost at
the typical metered rate. However, the tooltip wording and whether this estimate
belongs as a slice at all depends on the broader chart redesign decision.

## Options

### Option A — Costs-only donut (simplest change)

Redefine the donut to show only what was actually charged:

- 100% = gross bill = `importCost + fixedCharges`
- Slices: import cost (84.6%), fixed charges (15.4%)
- Percentages now answer: "what fraction of your gross bill was import vs
  standing charges?"
- Solar savings, export credit, and free import value are removed as slices
  and surfaced instead as a summary line or callout below the donut

**Pro:** Percentages become genuinely meaningful and easy to explain.  
**Con:** Loses the savings/credits story from the chart entirely. Those values
are already visible in the Solar Impact panel above.

### Option B — Waterfall / stacked bar (better story, bigger build)

Replace the donut with a horizontal bar that reads left-to-right:

```
[Without solar bill] ──────────────────────────────────
  minus solar savings         ─────────
  minus export credit    ────
  minus free import    ──
= Actual net cost  ────────────────────
```

This naturally handles both costs and credits without forcing them into a
shared total. The bar communicates the financial journey from "what you'd have
paid" to "what you actually paid" and shows exactly how solar reduced the gap.

**Pro:** Most honest and informative representation of the data.  
**Con:** Larger departure from the existing chart; requires more layout space
and chart implementation work.

### Option C — Two-section summary (no chart)

Remove the donut entirely and replace it with a structured two-column summary:

```
Costs                        Savings & credits
─────────────────────        ─────────────────────────
Import cost    €1,234.17     Solar savings   €640.36
Fixed charges    €223.99     Export credit   €170.24
─────────────────────        Free import     €71.77 est.
Gross bill     €1,458.16     ─────────────────────────
Net bill         €375.79     Total offset    €882.37
```

**Pro:** Completely transparent, no percentage ambiguity, no chart complexity.  
**Con:** Less visual impact; may feel like a downgrade if users expect a chart.

## Recommendation

Option A is the quickest win and makes the existing chart honest. Option B is
the right long-term answer if the chart is meant to tell the "solar impact on
bill" story rather than just a cost composition.

Option A can ship as an interim fix while Option B is designed properly.

## Acceptance Criteria

_To be completed when an option is chosen._

- The chart's 100% corresponds to a quantity that can be described in one
  plain sentence
- Every slice percentage answers a natural user question
- The free import estimate is shown with clear provenance (rate used, kWh
  quantity) so the user understands it is an approximation
- No euro and kWh values are combined into the same percentage calculation
