# P-078: Add regular-user sign-out action

## Objective

Add a straightforward sign-out action for normal end users so they can leave
the app intentionally instead of being forced to clear cookies or wait for
session expiry.

The current rewrite has admin logout support, but regular users do not yet have
an equivalent user-facing control. This leaves the product short of the UX
expectation already implied in the auth/gating design and makes the shared
header feel incomplete.

## Scope

- Add a regular-user sign-out action backed by the existing end-user auth
  system
- Expose the sign-out control from the shared signed-in header used across the
  main user-facing app
- Place the logout button immediately to the right of the Settings button in
  the header action row
- Ensure the control is available on the main signed-in user surfaces that use
  the shared header, including:
  - Live
  - Historical Day
  - Range History
  - Calendar
  - Leaderboard
  - Settings
- Ensure blocked/gated user states that already expect sign-out capability
  continue to offer a working sign-out path where applicable
- Route the user to the appropriate signed-out entry screen after logout
- Add focused coverage or verification for the normal sign-out flow

## Out of Scope

- Admin logout behavior, which already uses the separate admin auth flow
- User profile menus, avatars, or account-preferences redesign
- Multi-session account management
- Reworking the broader signed-in header beyond adding the logout action in the
  agreed position

## Acceptance Criteria

- Signed-in regular users can click a logout control from the shared header
- The logout button appears immediately to the right of the Settings button
- Logging out ends the normal user session and returns the user to the signed-
  out entry flow
- The logout action works consistently from Live, Historical Day, Range
  History, Calendar, Leaderboard, and Settings
- Waiting/gated states that expect a sign-out action still provide one after
  this work
- Admin-only auth/logout behavior is unchanged

## Dependencies

- `FE-007`
- Shared signed-in header from `P-075`
- Existing end-user auth/session flow

## Notes

- This is intentionally a small session-management story, not a full account
  menu or profile-management feature.
- The primary user-facing need is simple: make it easy for a normal user to
  leave the app explicitly.
