# P-062: Add GitHub-style yearly heat map to Range History

## Objective

Add a compact GitHub-style yearly heat map to `Range History` so users can scan
day-level patterns across a full year, switch between key metrics using the
same metric families as Calendar View, and jump directly from a heat-map day to
its detailed history.

## Scope

- Render a yearly heat map module on `Range History` only when the selected
  range is exactly one full calendar year
- Use the same metric-switching principle as Calendar View so users can swap
  the plotted metric without leaving the page
- Reuse the same metric color gradients already established on Calendar View
- Use a GitHub-style contributions grid layout:
  - months across the top
  - weekday labels down the side showing `Mon`, `Wed`, `Fri`
  - one square per valid day in the selected year
- Show a hover tooltip for each populated day with:
  - date
  - active metric value in the correct unit/currency
  - clear missing-data wording where needed
- Clicking a day navigates to that day's Historical Day screen
- Replace the GitHub footer help-link pattern with:
  - `View detailed calendar view for 2024` when the selected year is 2024
  - the link target should open the matching `/calendar?year=YYYY` screen
- Keep the heat map visually aligned with the established Range History design
  rather than looking like a pasted GitHub embed
- Reuse the existing year-scale range/calendar data model where practical

## Out of Scope

- Showing the heat map for partial-year or arbitrary custom ranges
- Adding a second separate yearly fetch contract just for the heat map
- Replacing the full Calendar View screen
- Adding ranking, streak, or anomaly layers in this first pass

## Acceptance Criteria

- A selected full calendar year on `Range History` renders the yearly heat map
- Partial-year ranges do not render the heat map
- The metric control updates the plotted daily colors using the same metric
  gradient rules as Calendar View
- Hovering a square shows the active metric value for that day
- Clicking a square opens `/history/[date]` for that day
- The grid uses GitHub-style placement with month labels above and `Mon` /
  `Wed` / `Fri` labels on the side
- The footer link reads `View detailed calendar view for YYYY` and opens the
  matching Calendar View year
- The heat map handles missing days and future days coherently with the product
  rules already established for Calendar View
- Automated coverage exists for:
  - full-year gating behavior
  - metric-to-color/value mapping
  - day-click navigation
  - calendar-view footer-link year targeting

## Dependencies

- `FE-006` Range History Screen
- `FE-015` Range History Financial Interpretation
- `P-056` interval-backed yearly range payloads
- `P-057` year-calendar history view
